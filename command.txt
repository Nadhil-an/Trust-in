=========================================================
  SREE LAKSHMI TRUST - STARTUP COMMANDS
=========================================================

== STEP 1 - Django Backend ==
cd backend
python manage.py runserver 0.0.0.0:8000

== STEP 2 - WhatsApp Gateway (PM2 - Auto-restarts if crashed) ==
(AUTO-STARTS ON PC LOGIN via Windows Startup folder)
To start manually if needed:
cd "C:\Users\NADIL\OneDrive\Desktop\sree Trust"
pm2 start ecosystem.config.js

To check gateway status:
pm2 list

To see gateway logs:
pm2 logs sree-trust-whatsapp-gateway

To restart gateway if needed:
pm2 restart sree-trust-whatsapp-gateway

To stop gateway:
pm2 stop sree-trust-whatsapp-gateway

== STEP 3 - Frontend (Web Dashboard) ==
cd frontend
npm run dev -- --port 5174

== MOBILE SETUP (Run these in ORDER in a new terminal) ==

STEP 1 - Clean Install (run once):
cd mobile
rmdir /s /q node_modules & del /f /q package-lock.json & npm install --legacy-peer-deps

STEP 2 - Start Expo (run every time):
cd mobile
set REACT_NATIVE_PACKAGER_HOSTNAME=10.15.73.21 && npx expo start -c
